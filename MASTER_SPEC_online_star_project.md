# 2. ОБЩАЯ ИДЕЯ ПРОДУКТА

Пользователь:

1. вводит дату рождения;
2. система рассчитывает персональную пятиконечную звезду;
3. пользователь видит всю геометрию своей звезды;
4. часть значений закрыта;
5. первая доступная сфера раскрывается;
6. пользователь читает подробную персональную расшифровку;
7. затем может последовательно приобрести следующий уровень;
8. после оплаты следующая сфера автоматически разблокируется;
9. пользователь может возвращаться к уже купленным результатам в своём аккаунте.

Продукт должен ощущаться не как магазин отдельных PDF, а как:

**постепенное раскрытие персональной карты человека.**

# 5. ПРАВИЛО ПРИВЕДЕНИЯ К 22 АРКАНАМ

Все вычисления работают в системе 22 арканов.

Если значение:

```text
1–22
```

оставляем без изменений.

Если:

```text
> 22
```

складываем цифры числа.

Если результат всё ещё >22 — повторяем.

Примеры:

```text
21 → 21
25 → 2 + 5 = 7
28 → 2 + 8 = 10
```

Вынеси это в отдельную функцию:

```ts
reduceToArcana(number)
```

---

# 6. ШЕСТЬ БАЗОВЫХ ЗНАЧЕНИЙ

Обозначим:

```text
A1 — Личность
A2 — Духовность
A3 — Деньги
A4 — Отношения
A5 — Здоровье
A6 — Миссия души
```

## A1 — Личность

День рождения.

```text
если day <= 22:
    A1 = day
иначе:
    A1 = reduceToArcana(day)
```

## A2 — Духовность

Число месяца рождения:

```text
A2 = month
```

## A3 — Деньги

Сумма всех цифр года:

```text
A3 = reduceToArcana(sumDigits(year))
```

Пример:

```text
1992
1+9+9+2 = 21
A3 = 21
```

## A4 — Отношения

```text
A4 = reduceToArcana(A1 + A2 + A3)
```

## A5 — Здоровье

```text
A5 = reduceToArcana(A1 + A2 + A3 + A4)
```

## A6 — Миссия души

```text
A6 = reduceToArcana(A1 + A2 + A3 + A4 + A5)
```

# 7. ПРОМЕЖУТОЧНЫЕ ТОЧКИ МЕЖДУ СФЕРАМИ

После пяти основных значений рассчитываются точки между соседними сферами.

```text
P12 = reduceToArcana(A1 + A2)
P23 = reduceToArcana(A2 + A3)
P34 = reduceToArcana(A3 + A4)
P45 = reduceToArcana(A4 + A5)
P51 = reduceToArcana(A5 + A1)
```

Они размещаются между соответствующими вершинами.

Пример из книги:

```text
A1 = 5
A2 = 3

P12 = 5 + 3 = 8
```

# 8. РОДОВЫЕ ПРОГРАММЫ И РОКОВАЯ ОШИБКА

По последним комментариям заказчика:

четыре промежуточные внутренние точки являются:

```text
ancestral_program
```

то есть **родовыми программами**.

Нижняя центральная точка между отношениями и здоровьем:

```text
P45
```

должна трактоваться как:

```text
fatal_error
```

то есть **«Роковая ошибка»**.

Важно:

одна и та же точка может участвовать сразу в двух соседних сферах.

Например:

```text
P12
```

находится между:

```text
Личность
Духовность
```

Поэтому:

**само число одно и то же**, но его текстовая интерпретация зависит от активной сферы.

Нужно хранить:

```text
value
point_type
sphere_context
interpretation
```

То есть:

```text
P12 = 8

в personality:
8 → одна трактовка родовой программы

в spirituality:
8 → другая трактовка той же родовой программы
```

Никогда не хранить трактовку только по:

```text
value = 8
```

Контекст сферы обязателен.

# 9. ВНУТРЕННИЕ ТРЕУГОЛЬНИКИ

Каждая из пяти основных сфер визуально является треугольником звезды.

Внутри него находится перевёрнутый треугольник.

Для каждой сферы используются:

```text
главная вершина сферы
две соседние промежуточные точки
```

Для сферы Personality:

```text
apex = A1
leftBase = P51
rightBase = P12
```

Внутренние значения:

```text
innerLeft =
reduceToArcana(apex + leftBase)

innerRight =
reduceToArcana(apex + rightBase)

innerBottom =
reduceToArcana(leftBase + rightBase)
```

Пример из книги:

```text
A1 = 5
P51 = 9
P12 = 8

9 + 5 = 14
5 + 8 = 13
9 + 8 = 17
```

То есть сфера Personality получает:

```text
5
9
8
14
13
17
```

Примени тот же принцип ко всем пяти сферам.

Не хардкодить значения.

Геометрия должна быть data-driven.
